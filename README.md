## 💡 My Approach

For each problem, I aim to:

1. Understand the problem statement and constraints.
2. Identify a suitable data structure or algorithm.
3. Develop a brute-force solution when appropriate.
4. Optimize the solution for time and space complexity.
5. Implement the solution in Java.
6. Test edge cases and verify correctness.
7. Analyze the time and space complexity.

## ⚡ Complexity Analysis

I aim to include efficient solutions with attention to:

- **Time Complexity:** The number of operations performed
  as input size increases.
- **Space Complexity:** The additional memory required
  by the algorithm.

Where applicable, I explore multiple approaches and compare
their trade-offs.

## 🔄 Automated GitHub Sync

This repository uses **LeetSync** to automate the process
of saving accepted LeetCode solutions to GitHub.

### Workflow

1. Solve a problem on LeetCode.
2. Submit the Java solution.
3. Once accepted, LeetSync synchronizes the solution.
4. The solution is committed to this repository.
5. GitHub records eligible commits in the contribution graph.

This automation helps maintain a consistent and organized
record of my coding practice.
